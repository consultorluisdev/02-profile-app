# LAB React Native — Projeto 02: Profile App

Tela de perfil para estudar **props**, Flexbox, `useState`, Dark Mode e `Platform`.

## Abrir no CodeSandbox

Link direto:

https://codesandbox.io/p/github/consultorluisdev/02-profile-app

1. Espere o `npm install`.
2. O Expo sobe sozinho (`expo start --tunnel`).
3. No iPhone SE, abra o Expo Go e escaneie o QR.

Se o CodeSandbox pesar, use o [Expo Snack](https://snack.expo.dev) — e o caminho mais leve para testar no celular.

## Conceitos

- Componentes + props (`Avatar`, `ProfileHeader`, `StatRow`, `ActionButtons`)
- `useState` (Seguir / Mensagem)
- `StyleSheet` + Flexbox (iPhone SE e telas maiores)
- `useColorScheme`
- `SafeAreaView`
- `Platform`
